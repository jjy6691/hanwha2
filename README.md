# 한밤의 늑대인간

한국어로 즐기는 한 기기용 원나잇 늑대인간 웹 게임입니다. 3~8명이 같은 화면을 차례로 사용합니다. 별도 설치나 서버 없이 `index.html`을 브라우저에서 열어 실행할 수 있습니다.

## GitHub에 직접 업로드하기

1. 이 압축 파일을 먼저 풉니다.
2. [jjy6691/Hanwha 저장소](https://github.com/jjy6691/Hanwha)를 엽니다.
3. 비어 있는 저장소에서는 **uploading an existing file**, 기존 파일이 있다면 **Add file → Upload files**를 누릅니다.
4. 압축을 푼 폴더 안의 파일들을 올리고 **Commit changes**로 저장합니다. ZIP 파일 자체나 상위 폴더를 올리는 것이 아니라, `index.html`이 저장소 맨 위에 오도록 올려 주세요.

업로드 후 저장소 맨 위에서 아래 파일들이 보여야 합니다.

```text
index.html
style.css
setup.js
game.js
README.md
.nojekyll
```

`.nojekyll`은 별도 빌드 없이 정적 파일을 게시하기 위한 빈 파일입니다. 파일 선택 창에서 숨김 파일로 보일 수 있습니다. 게임 파일에는 별도 빌드가 필요하지 않습니다.

## GitHub Pages로 배포하기

1. 저장소의 **Settings → Pages**를 엽니다.
2. **Build and deployment → Source**에서 **Deploy from a branch**를 고릅니다.
3. **Branch**는 `main`, 폴더는 `/(root)`로 선택하고 **Save**를 누릅니다.
4. 배포가 끝나면 Pages 화면에 표시되는 주소를 엽니다. 진행 상태는 저장소의 **Actions**에서도 볼 수 있습니다.

기본 주소는 `https://jjy6691.github.io/Hanwha/`입니다. 이 주소는 업로드와 Pages 배포를 완료한 뒤 사용할 수 있습니다.

공식 안내: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## 플레이 방법

1. 인원수와 플레이어 이름을 정합니다.
2. 추천 조합을 사용하거나 각 역할의 +/− 버튼으로 수량을 조절합니다. 플레이어 수보다 3장 많은 카드가 필요합니다.
3. 기기를 차례로 넘겨 자신의 역할을 비공개로 확인합니다.
4. 야간 역할 행동을 진행하고 낮에 토론합니다. 선택적으로 3분 타이머를 사용할 수 있습니다.
5. 각자 투표한 뒤 최종 역할과 결과를 확인합니다.

지원 역할: 늑대인간, 하수인, 예언자, 강도, 말썽꾸러기, 불면증 환자, 주민.

## 현재 버전의 범위

- 온라인 멀티플레이와 저장 기능은 없습니다. 새로고침하면 진행 중인 게임이 초기화됩니다.
- 8인 플레이를 위한 사용자 조합으로 주민 카드를 최대 8장까지 선택할 수 있습니다.
- 비공식 프로토타입이며 원작의 모든 역할과 세부 규칙을 구현하지는 않았습니다. 현재 최다 득표 동률은 모두 처형되며, 하수인의 별도 승리 조건은 반영하지 않습니다. 정식 규칙과 동일한 판정이 필요한 경우 보완이 필요합니다.
- 글꼴은 Google Fonts를 사용합니다. 인터넷에 연결되지 않으면 기본 글꼴로 표시됩니다.

배포 설정과 계정 정보, 작업용 파일은 이 업로드 파일에 포함되어 있지 않습니다.
